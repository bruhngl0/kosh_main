August 2026 workflow

01

Create the cycle

Start a draft cycle with August 1 as the start date. The system creates 28 numbered days and groups them into four phases.

Draft status keeps the plan editable.
POST /api/v1/cycles

{
  "name": "August 2026 Cycle",
  "cycleNumber": 2,
  "durationDays": 28,
  "weekStart": "2026-08-01",
  "subscriberCount": 37,
  "foodCostTargetPercent": 30
}
02

Assign the recipes

Each day has four meal slots. Assign a published recipe version to breakfast, snack, lunch, and dinner.

Meal codes: BF = breakfast · SN = snack · LU = lunch · DI = dinner.
PUT /api/v1/cycles/CYCLE_ID/days/1/meals/DI

{
  "mealType": "DI",
  "recipeVersionId": "RECIPE_VERSION_ID",
  "servings": 37
}
03

Review and publish

The planner checks that all days have four assignments. The calendar also highlights dinner protein repeats within a four-day window.

Do not publish until missing assignments and conflicts are reviewed.
PATCH /api/v1/cycles/CYCLE_ID

{}
04

Generate kitchen work

Generate advance-prep tasks from recipe steps marked as mandatory or critical. The weekly production view shows what the kitchen needs to execute.

POST /api/v1/cycles/CYCLE_ID/prep-tasks/generate
05

Generate purchase orders

Kōsh multiplies recipe quantities by servings, subtracts current stock, groups the remaining demand by preferred vendor, and creates draft purchase orders.

POST /api/v1/purchase-orders/generate

{
  "cycleId": "CYCLE_ID",
  "weekNumber": 1
}
06

Receive and reconcile stock

When ingredients arrive, record a receiving movement. Inventory balances update transactionally and below-par items remain visible for follow-up.

POST /api/v1/inventory/movements

{
  "ingredientId": "INGREDIENT_ID",
  "type": "RECEIVE",
  "quantityDelta": 2,
  "reference": "Vendor delivery — August Week 1"
}

What each screen is responsible for

Cycle Planner

Calendar, meal assignments, protein conflict checks, prep tasks, and weekly production.

Recipe Database

Versioned ingredients, method steps, nutrition, allergens, advance prep, and plating notes.

Inventory

Stock balances, par levels, receiving movements, vendors, costs, and CSV export.

Procurement

Demand aggregation, preferred-vendor grouping, draft purchase orders, and outreach preparation.
